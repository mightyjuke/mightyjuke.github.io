# Squadstorm public website

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML/CSS on GitHub Pages, no JavaScript or build dependencies.

## Users
Players discovering Squadstorm, players seeking support, and readers of its advertising privacy disclosures.

## Product Purpose
Present Squadstorm: Zombie Shooter by Kevin Mok and provide a stable public privacy policy for the stores and AdMob.

## Capabilities and Constraints
The game has 24 stages, six weapons, three bosses, Endless mode and a Daily Challenge. Core gameplay is offline; optional rewarded ads use Google AdMob. Store URLs are not yet available. Website publication is authorized at /squadstorm/; private game source remains in red-blue-man.

## Brand Commitments
Inherit Squadstorm's real artwork, navy #0b2038, orange #ffac60, pale text, and Barlow Condensed headings. Support contact: kevinmokex@gmail.com. Preserve the existing privacy disclosures dated 1 October 2026.

## Product Principles
Show real game imagery. State availability honestly. Keep support and privacy readily accessible. Work without JavaScript.
