# Stairs Rush Reloaded website

## Platform
web

## Purpose
Help players discover Stairs Rush Reloaded build47, see its game and pilots, reach the current App Store listing, and find privacy/support information.

## Scope
Buildless HTML/CSS with a small progressive JavaScript realm selector. Hosted at mightyjuke.github.io/stairrushreloaded/. Preserve the root developer hub and other games. No site analytics, sign-up, cookies, external fonts, or third-party embedded content.

## Product facts
Version1.3.5 build47 has five underground realms and eight pilots, left/right descent, rechargeable skills after eight new floors, coins/gems/unlocks and local personal bests. Actual compiled-build47 screenshots substantiate the marketing. The current public iOS store is an earlier version; Android47 is in testing. Never conflate the latest showcased build with store availability.

## Privacy
Android47 is offline with no internet permission, ads or billing and cloud backup disabled. iOS uses Google AdMob/UMP, Apple StoreKit and Game Center for supported features. Local progress is stored on-device. Public support contact is Kevin Mok at kevinmokex@gmail.com.

## Brand
Use the game's existing The Deep campaign art, pixel pilots, midnight-violet palette, pink actions, cyan links, Pixelify display and Barlow body fonts. Policy reading must remain comfortable on phones.
